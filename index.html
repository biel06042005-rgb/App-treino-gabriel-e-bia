Como instalar na tela inicial

📱 iPhone (Safari)

  1. Abra este link no navegador Safari.
  2. Toque no botão Compartilhar (o quadrado com a seta para cima).
  3. Escolha "Adicionar à Tela de Início".
  4. Toque em "Adicionar" — pronto, o ícone aparece na tela inicial.

🤖 Android (Chrome)

  1. Abra este link no navegador Chrome.
  2. Toque no menu (três pontinhos) no canto superior direito.
  3. Escolha "Instalar app" ou "Adicionar à tela inicial".
  4. Confirme — o app aparece com ícone próprio, como um app normal.

O app funciona 100% offline depois da primeira visita — inclusive as ilustrações de demonstração dos exercícios.
